# FocusBoard submission checklist

## Before GitHub
- [ ] Install dependencies with `npm install`
- [ ] Run with `npm run dev`
- [ ] Create a task and verify it appears
- [ ] Edit a task and verify it updates rather than duplicates
- [ ] Delete a task and test both Cancel and Confirm
- [ ] Change task status and check statistics
- [ ] Search using lowercase and uppercase text
- [ ] Combine status and priority filters
- [ ] Refresh and verify localStorage persistence
- [ ] Test all three Focus Notes slides
- [ ] Test at 390px, 768px and 1440px
- [ ] Run `npm run build`
- [ ] Compare with the original Figma and replace placeholder slide copy if needed
- [ ] Add genuine screenshots to `screenshots/`

## Before sending to the company
- [ ] README contains the real GitHub URL
- [ ] README contains the live deployed URL
- [ ] AI_USAGE.md truthfully describes AI assistance
- [ ] GitHub repository is public if the company asked for public access
- [ ] No passwords, tokens, personal data or `.env` files are committed
- [ ] Live URL opens in a private/incognito browser
- [ ] Final GitHub commit includes all last-minute fixes
- [ ] Email/message includes both GitHub and live application links
